# TorchBotTiny fully offline chatbot built with PyTorch. No API keys. Train on your own dialogues. Runs in the terminal on Windows, macOS, and Linux.TorchBot is a small, private AI chatbot that runs entirely on your computer. It uses pure PyTorch (a 2-layer LSTM, ~2M parameters) plus phrase matching over a dialogue file you can edit. There are no cloud APIs, no API keys, and no data sent online after install. It is aimed at learning, experimentation, and offline demos—not at replacing ChatGPT.Instructions for installation:Requirements:Python 3.10 or newer (3.11 or 3.12 recommended)~2 GB free disk space (mostly for PyTorch)2 GB RAM minimum (4 GB+ recommended)Windows, macOS, or LinuxInternet only for the first setup (pip install).
